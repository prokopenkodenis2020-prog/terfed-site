# TERFED — сайт-каталог виробника сільськогосподарської техніки

Production-ready статичний сайт для TERFED. Проєкт містить каталог, окремі сторінки техніки, пошук, фільтри, порівняння, підбір за потужністю трактора, YouTube-відео, PDF-каталог та Netlify Forms для заявок.

## Запуск локально

У VS Code відкрийте папку проєкту і запустіть `index.html` через Live Server.

Для повноцінного онлайн-режиму рекомендовано Netlify. Не використовуйте `file:///` як спосіб перевірки вбудованого YouTube-плеєра.

## Продакшн

Дивіться `CLIENT-HANDOFF.md` — там є повна покрокова інструкція для GitHub + Netlify + власний домен + форми.

## YouTube

ID відео змінюється у `config.js`:

```js
VIDEO_ID: "tsgqYKhNUSQ"
```

## Форма

Форма має ім’я `terfed-lead`, надсилається методом POST на `/success.html` та обробляється Netlify Forms після деплою. Перед першим робочим запуском обов’язково налаштуйте email notification у Netlify.

## Домен

За замовчуванням в `robots.txt`, `sitemap.xml` і JSON-LD вказано `https://terfed.com`. Якщо замовник використовує інший домен, замініть його перед запуском у продакшн.
