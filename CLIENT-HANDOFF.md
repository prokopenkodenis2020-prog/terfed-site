# TERFED — передача сайту замовнику

Цей пакет підготовлено як production-ready статичний сайт TERFED. Дизайн і структура каталогу збережені; додано нормальну форму заявок через Netlify Forms, сторінку успішного надсилання, 404, технічні заголовки та інструкцію деплою.

## 1. Що вже готово

- Сайт TERFED на HTML/CSS/JavaScript без збірки.
- Каталог і окремі сторінки техніки.
- YouTube-відео з ID `tsgqYKhNUSQ`.
- Форми `terfed-lead` на головній і сторінках товарів.
- `success.html` після успішного надсилання.
- Honeypot-поле для базового захисту від ботів.
- `netlify.toml`, `_headers`, `robots.txt`, `sitemap.xml`.
- PDF-каталог 2026 у `assets/docs/`.

## 2. Важливо перед публікацією

1. Придбайте домен, який буде використовувати TERFED.
2. Якщо домен буде не `terfed.com`, замініть базовий домен у `robots.txt`, `sitemap.xml` та JSON-LD у `index.html`.
3. Не кладіть у репозиторій паролі, API-ключі або інші секрети.

## 3. Рекомендована схема

`GitHub → Netlify → власний домен → Netlify Forms → email-сповіщення менеджеру`

## 4. Варіант A — простий ручний запуск

1. Зайдіть у Netlify.
2. Створіть новий сайт через ручний deploy / drag-and-drop.
3. Розпакуйте цей ZIP.
4. Перетягніть папку, де лежить `index.html`, у зону деплою.
5. Отримайте тимчасову адресу `*.netlify.app`.

## 5. Варіант B — рекомендований для замовника

1. Створіть GitHub-репозиторій, наприклад `terfed-site`.
2. Завантажте в репозиторій всі файли і папки цього пакета.
3. У Netlify створіть новий проєкт з GitHub-репозиторію.
4. Для цього сайту build command не потрібен, а publish directory — корінь репозиторію (`.`).
5. Після підключення GitHub кожне оновлення гілки production/main буде публікувати нову версію сайту.

## 6. Підключення домену

1. У Netlify відкрийте Site dashboard → Domain management.
2. Додайте домен, який уже придбали.
3. Якщо використовуєте Netlify DNS — делегуйте домен на Netlify DNS за інструкціями в кабінеті.
4. Якщо залишаєте DNS у реєстратора — внесіть DNS-записи, які покаже Netlify.
5. Перевірте, що відкриваються і основний домен, і `www` (якщо його налаштовано).
6. Переконайтеся, що сайт відкривається через HTTPS.

## 7. Налаштування заявок

1. Після першого deploy відкрийте Netlify → Forms.
2. Переконайтеся, що форма `terfed-lead` визначилася.
3. Відкрийте налаштування сповіщень форм.
4. Додайте email-сповіщення на адресу, яку контролює менеджер TERFED, наприклад `agrokomplekt@ukr.net`.
5. Надішліть одну реальну тестову заявку з сайту.
6. Перевірте: а) запис у Netlify Forms; б) лист на email менеджера; в) сторінку `success.html`.

## 8. YouTube

Відео налаштоване через `config.js`:

`VIDEO_ID: "tsgqYKhNUSQ"`

На опублікованому сайті відео має бути вбудованим у блок `TERFED у роботі`. Локально `file:///` може використовувати fallback із кнопкою переходу на YouTube.
